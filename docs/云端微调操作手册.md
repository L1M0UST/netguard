## 1. 确认有没有模型、模型名称

**概念澄清**：LLaMA-Factory 本身**不自带模型**；它按 `model_name_or_path` 在运行时从本地目录或
ModelScope/HuggingFace 拉取。所以"确认是否有模型"= 查本地缓存目录 + 查平台共享目录 + 没有就下载。

```bash
# 1) 扫本地常见缓存/模型目录，看已有哪些模型
ls ~/.cache/modelscope/hub 2>/dev/null; ls ~/.cache/huggingface/hub 2>/dev/null
find / -maxdepth 4 -type d \( -name "Qwen*" -o -name "*jiutian*" -o -name "*JIUTIAN*" \) 2>/dev/null | grep -v proc

# 2) 确认平台是否预置了模型盘（有的平台把模型放在共享只读盘）
df -h | head -10; ls /mnt /data /models 2>/dev/null
```

**没有就用 ModelScope 下载（国内直连快）**——我们用 Qwen3-8B：
```bash
pip install -U modelscope
modelscope download --model Qwen/Qwen3-8B --local_dir ./models/Qwen3-8B
# 备选（HF 镜像）：export HF_ENDPOINT=https://hf-mirror.com
# huggingface-cli download Qwen/Qwen3-8B --local-dir ./models/Qwen3-8B
```

**验证模型完整可用**（safetensors 齐全 + 能加载 config）：
```bash
ls -lh ./models/Qwen3-8B    # 应有 *.safetensors(约16GB)、config.json、tokenizer.json 等
python - <<'EOF'
from transformers import AutoConfig, AutoTokenizer
cfg = AutoConfig.from_pretrained("./models/Qwen3-8B", trust_remote_code=True)
tok = AutoTokenizer.from_pretrained("./models/Qwen3-8B", trust_remote_code=True)
print("model_type:", cfg.model_type, "| vocab:", cfg.vocab_size, "| tokenizer ok:", tok is not None)
EOF
```

## 2. 数据集准备（本机构建 → 上传 → 注册）

### 2.1 本机构建（一条命令，已验证）
```powershell
# 在本机 taishi_platform 目录（产出 train.jsonl / val.jsonl / dataset_info.json）
.venv\Scripts\python.exe scripts\build_finetune_dataset.py --per-class 500 --flywheel-limit 1500
```
三层来源自动融合：官方 1.1 万条（ground truth 8 类均衡）+ 平台数据飞轮（M1 真实研判记录）+
注入对抗样本。输出格式（alpaca，与 qwen3_nothink 模板对齐）：
```json
{"instruction": "你是网络安全态势感知中心的AI告警研判助手。…只输出一行JSON：{\"label\":…}",
 "input": "时间: …\n方法: POST\n源IP: …\n目的IP: …\nUser-Agent: …\nURL路径: …\n请求体: …",
 "output": "{\"label\":\"SQL注入攻击\",\"confidence\":0.94,\"risk\":\"高\",\"mitre\":\"T1190 …\"}"}
```

### 2.2 上传到云
对象存储控制台上传 `dataset/cqsec_judge/` 三个文件 → 实例里挂载/拷贝到 LLaMA-Factory 的 `data/` 目录：
```bash
# 假设 LLaMA-Factory 在 /root/LLaMA-Factory
cp /mnt/objectstore/cqsec_judge/train.jsonl  /root/LLaMA-Factory/data/
cp /mnt/objectstore/cqsec_judge/val.jsonl    /root/LLaMA-Factory/data/
# 注册数据集（合并到 LLaMA-Factory 的 data/dataset_info.json）
python - <<'EOF'
import json
p = "/root/LLaMA-Factory/data/dataset_info.json"
info = json.load(open(p, encoding="utf-8")) if __import__("os").path.exists(p) else {}
info.update(json.load(open("/mnt/objectstore/cqsec_judge/dataset_info.json", encoding="utf-8")))
json.dump(info, open(p, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
print("registered:", list(info.keys()))
EOF
# 自检：数据集能否被 LLaMA-Factory 读取
llamafactory-cli train --dataset cqsec_judge_train --max_samples 3 --stage sft \
  --model_name_or_path ./models/Qwen3-8B --template qwen3_nothink --dry_run
```

## 3. 微调（910B = 纯 LoRA bf16，勿用 QLoRA）

保存为 `cqsec8b_lora_sft.yaml`：
```yaml
### 模型
model_name_or_path: ./models/Qwen3-8B
trust_remote_code: true

### 方法
stage: sft
do_train: true
finetuning_type: lora
lora_rank: 16
lora_alpha: 32
lora_target: all

### 数据
dataset: cqsec_judge_train
eval_dataset: cqsec_judge_val
template: qwen3_nothink
cutoff_len: 2048
overwrite_cache: true
preprocessing_num_workers: 16

### 输出
output_dir: saves/qwen3-8b-cqsec-judge/lora-sft-v1
logging_steps: 10
save_steps: 200
plot_loss: true

### 训练
per_device_train_batch_size: 8
gradient_accumulation_steps: 2
learning_rate: 5.0e-5
num_train_epochs: 3.0
lr_scheduler_type: cosine
warmup_ratio: 0.05
bf16: true

### 验证
val_size: 0.0
per_device_eval_batch_size: 8
eval_strategy: steps
eval_steps: 100
```
启动与监控：
```bash
cd /root/LLaMA-Factory
llamafactory-cli train cqsec8b_lora_sft.yaml          # 前台（推荐首次）
# 或后台：nohup llamafactory-cli train cqsec8b_lora_sft.yaml > train.log 2>&1 &
watch -n 2 npu-smi info                                # 另开终端看显存/利用率
tail -f train.log                                      # 观察 loss 下降与 eval 指标
```
判读：loss 前几百步快速下降后趋平即可；eval label 准确率参考值 ≥0.95（我们任务上限高）。
**先跑 `--dry_run` 和 100 步短训验证格式，再放满 3 epochs。**

## 5. 冒烟评测（部署前最后一道闸）

```bash
# 交互冒烟：粘一条告警，应输出一行 JSON（label/confidence/risk/mitre）
llamafactory-cli chat --model_name_or_path models/qwen3-8b-cqsec-judge-merged --template qwen3_nothink
```
批量评测（label 准确率，对齐验证集）：
```bash
pip install vllm vllm-ascend   # 第6步部署用的包，这里先复用其离线推理
python - <<'EOF'
import json, re
from vllm import LLM, SamplingParams
MODEL = "models/qwen3-8b-cqsec-judge-merged"
LABELS = ["SQL注入攻击","XSS跨站脚本攻击","目录遍历攻击","文件包含攻击","远程命令执行攻击","CSRF攻击",
          "Java反序列化漏洞利用攻击","文件上传攻击","暴力破解攻击","扫描探测攻击","Webshell通信攻击",
          "C2回连攻击","SSRF攻击","XXE攻击","SSTI攻击","正常访问"]
rows = [json.loads(l) for l in open("data/cqsec_judge_val.jsonl", encoding="utf-8")][:200]
llm = LLM(model=MODEL, max_model_len=4096)
sp = SamplingParams(temperature=0.1, max_tokens=128)
prompts = [[{"role":"user","content": r["instruction"]+"\n\n"+r["input"]}] for r in rows]
outs = llm.chat(prompts, sp)
hit = bad = 0
for r, o in zip(rows, outs):
    m = re.search(r'"label"\s*:\s*"([^"]+)"', o.outputs[0].text)
    ok = bool(m and m.group(1) in LABELS and f'"{m.group(1)}"' in r["output"])
    hit += ok; bad += (m is None)
print(f"label命中: {hit}/{len(rows)} = {hit/len(rows):.3f} | 未解析: {bad}")
EOF
```
判读：命中 ≥0.95 可上线；未解析率高 → max_tokens 调大或数据 output 格式再收敛。

## 6. 云端部署（vllm-ascend，OpenAI 兼容）+ 平台接入

```bash
# 依赖锁定（版本必须配套）：CANN 9.1.0 + torch 2.10 + torch_npu 2.10.post4 + vllm 0.11+ / vllm-ascend 0.23.x
pip install vllm vllm-ascend
# 启动服务（served-model-name 建议固定，平台配置要用）
vllm serve models/qwen3-8b-cqsec-judge-merged \
  --served-model-name cqsec-8b --host 0.0.0.0 --port 8000 \
  --max-model-len 4096 --gpu-memory-utilization 0.85
# 冒烟
curl http://127.0.0.1:8000/v1/chat/completions -H "Content-Type: application/json" -d '{
  "model": "cqsec-8b", "temperature": 0.1, "max_tokens": 128,
  "messages": [{"role":"user","content":"<能力①指令>\n\n<告警7字段行>"}]}'
```
**平台接入（本机 taishi_platform 改 .env，零代码）**：
```ini
CQSEC_BASE_URL=http://<云实例公网IP或隧道>:8000
CQSEC_MODEL=cqsec-8b
```
> 公网暴露务必过网关/隧道并加鉴权或自定义 UA（此前 Cloudflare 拦 python UA 的教训）；
> 云端不可用时客户端自动回本机 4B（`http://127.0.0.1:8008`），双链路互为兜底。

## 7. 常见报错对照

| 现象 | 原因 → 处置 |
|---|---|
| `torch_npu` 导入失败 / npu 不可见 | 镜像不含 CANN 或版本不配 → 换官方 910B 镜像；截图发我 |
| 训练报 bitsandbytes/4bit 相关错误 | NPU 上 QLoRA 非一等公民 → **删掉 quantization_bit，用纯 LoRA bf16** |
| NPU OOM | per_device_train_batch_size 8→4（gradient_accumulation 2→4 等效） |
| 数据集找不到/字段错 | dataset_info.json 未注册或文件名不符 → 重跑第 2.2 步注册脚本 |
| 输出不是 JSON/带思考标签 | template 不对（必须 qwen3_nothink）或训练数据格式漂移 → 抽查 jsonl |
| ModelScope/HF 下载慢 | HF 用 hf-mirror.com；ModelScope 一般直连快 |
| checkpoint 写入极慢 | 输出目录在高性能存储/对象存储挂载上 → output_dir 指到实例本地盘，产物再回传 |
