# 前端一次全跑通 · 验收测试指南

> 版本说明（2026-09-23）：本文保留早期 UI 演示步骤，其中耗时、告警数和 PCAP 描述是历史样例预期，不作为当前性能/准确率证据或完整协议解码承诺。正式复现请以 `赛前验证与复现说明.md` 和 `docs/evidence/competition_acceptance_*.json` 为准；PCAP 能力边界见 `数据来源与PCAP边界.md`。

> 目标：在浏览器里把平台全部功能过一遍。全程约 15-20 分钟（含两次任务分析）。
> 测试数据在 `tests_integration/fixtures/`，服务启动见文末。

## 〇、准备

1. 双击 `scripts\start_all.bat`（启动 M3 网关 :8001 + 编排器）。
2. 本地模型（可选，用于问答知识类与级联路由第一档）：
   `E:\code\2026年第二届重庆市AI大模型创新应用大赛\start_all.bat`（端口 8008）。
   *不启动时平台自动降级：问答知识类回退本地检索，级联直接走 DeepSeek-flash。*
3. 浏览器打开 **http://127.0.0.1:8001** —— 页面顶部应出现四个新按钮：
   `⚡ 一键自动调查`、`🛡 置信度卡片`、`🔍 威胁情报查询`、`↺ 重置演示`。

## 一、CSV 全链路（主测试，约 8 分钟）

1. `↺ 重置演示` → 确认（多次测试前都建议先重置；重置会清空全部任务与产物，运行中的任务会拒绝重置）。
2. `＋ 新建分析任务` → 选择 **`tests_integration\fixtures\sample_alerts.csv`**（380 行，8 类攻击+正常，每类 40 条）→ 创建。
3. **SSE 进度**：任务卡实时显示"等待→running→completed"，模块状态显示 M1/M2 两个模块的进度与消息。
4. 完成后（约 5-8 分钟，含 60 次级联/研判调用）：
   - **态势总览**：指标卡（告警总数 281/攻击链 281）、威胁类型分布饼图（应含 8 类官方中文标签）。
   - **告警中心**：6577→281 条告警；筛选"全部严重等级=high"；点击一条告警查看详情与关联链；`POST view-alert` 已读标记。
   - **攻击链分析**：链下拉切换；SVG 阶段图缩放；证据面板能看到**载荷摘要与官方中文标签**。
5. **🛡 置信度卡片**：点按钮 → 面板列出 Top10 链的"8 因子条形图 + 反幻觉校验结论 + 惩罚项"（②的核心演示）。
6. **⚡ 一键自动调查**：点按钮 → SSE 轨迹流式输出"载入→情报富化→逐链调查(含置信度摘要)→反幻觉校验→结论"（⑤）。
7. **智能问答**（查询分析结果按钮）：
   - 统计类：`本任务告警总数多少？高危告警多少条？` → 秒回与页面同源数字（零幻觉）。
   - 知识类：`SQL注入攻击怎么修复？` → 本地 cqsec 模型回答（需 8008 在线，约 10-40 秒）。
8. **🔍 威胁情报查询**：
   - 输入 `8.8.8.8` → 美国·境外·IOC 未命中；
   - 输入 `1.2.4.8` → 中国·北京；
   - 输入 `10.60.33.18` → 内网地址；若输入本次任务里出现过的攻击源 IP → 额外显示"出现在当前分析任务中"；
   - 输入 `SQL注入攻击` → ATT&CK 映射+简介+检测+处置；输入 `扫描` → 模糊匹配扫描探测。
9. **报告导出**：分析工作台 `导出 JSON` / `导出 PDF`（中文 PDF 含报告摘要与证据）。
10. 再次 `↺ 重置演示`，验证环境干净（任务列表清空）。

## 二、PCAP 多模态（约 1 分钟）

1. （已重置状态下）`＋ 新建分析任务` → 选择 **`tests_integration\fixtures\sample_traffic.pcap`**（54 包：正常业务+端口扫描+C2 心跳剧本）。
2. 完成后查看：1 条攻击链（`TA0043/T1595 Active Scanning`，severity=medium），告警标签 **扫描探测攻击**；
   证据摘要是 GLYPH 流文本：`GLYPH flow 45.61.10.9>10.60.33.18 proto=TCP pkts=46 distinct_dst_ports=40 PORT_SWEEP dst_ports=21,22,...`。
   正常业务流被降噪正确丢弃（不产生告警）。
3. 情报查询输入 `45.61.10.9` → 加拿大·境外。

## 三、提示注入自防（约 1 分钟）

1. 重置后上传 **`tests_integration\fixtures\injection_alerts.csv`**（30 正常 + 4 条藏有"忽略之前指令/系统提示词"载荷）。
2. 完成后：告警中心能看到 `prompt_injection` 命中的告警（对 AI 接口的注入探测）；
   处理日志 `logs\orchestrator.log` 与 M1 status 的 `metrics.prompt_injection_blocked` > 0（LLM 实际收到的是 `[注入内容已拦截]`）。
3. 级联路由统计：M1 status 的 `metrics.cascade`（local_hits=本地 cqsec 判决数 / escalations=升级 DeepSeek 数）。
