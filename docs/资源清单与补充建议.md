# 资源清单与补充建议

## 已接入

- `data/geo/ip2region.xdb`：离线 IP 地理归属。
- `workspace/m1/local_ioc/ioc.sqlite3`：Spamhaus DROP、OpenPhish 等本地 IOC。
- `data/threat_intel/*.parquet`：IP、域名、Hash、CVE 种子/运行数据。
- `m3/knowledge/attack_intro.json`：项目常见攻击类型中文说明。
- `data/threat_intel_public/cisa_kev.json`：CISA 已知在野利用漏洞目录的离线精简索引。
- `data/threat_intel_public/mitre_attack_enterprise.json`：MITRE ATT&CK Enterprise 技术、平台、战术与缓解措施的离线精简索引。
- 可选在线层：AlienVault OTX、AbuseIPDB、IP-API；失败时不影响离线查询。

## 更新方式

运行 `python scripts/update_public_intel.py`。脚本只下载公开权威源，生成紧凑 JSON 与带数量/更新时间的 `manifest.json`；页面查询不直接依赖 50MB 级原始 STIX 文件。

## 后续可补充

- NVD CVE/CVSS 与 EPSS：用于“已利用 + 利用概率 + 资产暴露”联合排序。
- FIRST CVSS/CWE/CAPEC：补齐漏洞成因和攻击模式解释。
- 内部资产 CMDB：当前资产重要性不足，接入业务等级、互联网暴露和负责人后，置信度卡片的资产因子才更可靠。
- DNS/证书被动解析与 ASN 历史：用于基础设施聚类，但需明确数据许可、保留期与调用预算。
