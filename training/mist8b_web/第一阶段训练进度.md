# MiST-8B Web 单事件研判：第一阶段训练

更新时间：2026-11-16。此记录描述当前作业和可复现配置；训练和评测指标以实际生成的报告为准。

## 已完成

- 已连接用户授权的算力实例，实际设备为 RTX 4090（24,564 MiB 显存），GPU 支持 BF16。
- 训练环境位于服务器 `/root/sj-tmp/cqsec_mist8b_web_20261115/env312`。已验证 Python 3.12.7、PyTorch 2.5.1/CUDA 12.4、LlamaFactory 0.9.4、Transformers 4.53.3、PEFT 0.16.0、bitsandbytes 0.45.5 的 GPU 及 QLoRA 运行。
- 比赛数据和 D1 Web 数据按载荷族划分、近重复审计并整理为系统使用的单条用户消息与四段输出。训练 29,411 条，完整验证集 4,472 条；均衡验证子集 300 条；封存测试集 6,537 条留在本机，未上传训练机。
- 训练长度检查：29,411 条均在 2,048 token 截断范围以内（保留 16 token 余量），最大 1,835 token，平均约 330 token。
- 补充检查了比赛样本的单字段捷径：验证集约 98% 源 IP 在训练集出现过，但按该 IP 的训练集多数标签直接预测，验证集整体准确率约 20.2%；这只是一个简单基线，不能排除其他组合特征或语义相似性泄漏。
- MiST 原版 tokenizer 配置面向新版 Transformers。在单独的兼容目录保留原始权重与原文件，并把列表字段转换为旧版配置；13 个特殊标记 ID 已与原始 tokenizer 核对，LlamaFactory 训练提示词和评测提示词的 token ID 已核对一致。
- 使用随机初始化的微型 Qwen3 测试了两步 QLoRA、适配器保存、基座和适配器推理。该结果仅证明训练与评测基础设施可运行，不是 MiST 模型效果。

## 当前作业

服务器工作目录：`/root/sj-tmp/cqsec_mist8b_web_20261115`。

MiST 官方基座：`dreamgroup/MiST-8B`，版本 `9ba377df00b9e830849fce8ebbe568a9a84774f2`。权重约 16.38 GB；下载支持断点续传，完成后将核验官方 SHA-256。当前状态由本机 `E:\platform_taishi\mist8b-web-data\training-status.txt` 持续更新。

后台作业在权重验证成功后自动执行：真实 MiST 5 步试训 → 均衡验证集基座评测 → 30 步性能测量 → 一轮 QLoRA SFT → 同一验证集适配器评测 → 对比报告和适配器归档。任一步失败即停止；结果仅代表模型单事件验证，不代表平台全链路验收。

第一轮配置：4 bit NF4 双重量化、LoRA rank 16 / alpha 32 / dropout 0.05、BF16、学习率 5e-5、batch 1、梯度累积 16、1 epoch、最大长度 2,048。样本回答由数据源标签与规则片段模板生成，并非逐条人工复核的专家标注。

## 评估边界

验证集分组和近重复过滤是近似方法，不能证明完全无数据泄漏；数据源原始标签尚未逐条独立复核。比赛数据可能与既有 4B 模型的训练材料有重叠，不能据此把旧 4B 的比赛分数视为严格独立的外部测试。待训练完成后，先报告同一验证集上的前后对比，再使用本机封存测试和后续外部数据评估；系统接入和全链路收益另行验证。
